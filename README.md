# Fitness

Meine Trainings- und Übungspläne als Web-Apps (PWA). Jeder Ordner ist eine eigene App, die offline funktioniert und sich auf dem iPhone zum Home-Bildschirm hinzufügen lässt.

| Ordner | Plan |
|---|---|
| [`dehnen/`](dehnen/) | Dehnprogramm Beine & Hüfte, 15 Min. täglich, 4 Level |

**Installieren:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Der Fortschritt wird nur lokal auf dem Gerät gespeichert.
